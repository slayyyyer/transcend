01 / Comparison

Every aggregate metric improved.

Preserved 350M step 38,000 versus 800M final step 91,691 on exactly the same retained newstest2014 rows. Beam 4 is the dev-tuned setting; greedy remains the model default.

Read this first

BLEU in the mid-20s is a gist-level score, not a percentage of correct sentences. The model can carry the main idea of a straightforward news sentence; it still drops details and produces wrong words.

Headline and tables use the final step-91,691 checkpoint. The dev-selected step-77,000 checkpoint is slightly lower but also above the 350M baseline; the comparison report includes both.

02 / Data ablation

Two data additions. ParaCrawl wins at both scales.

At 350M, each arm keeps the 19.8M-parameter model and the 350M-token budget, then adds about 99k everyday-language pairs to the same 2.1M-pair baseline. ParaCrawl improves every cell; Tatoeba's gain is FR→EN-specific. A fresh 800M ParaCrawl run now confirms the same direction at the larger budget.

Tatoeba-only

direction-specific

99,135 added pairs, mostly short conversational sentences. The EN→FR point estimates are positive but both 95% intervals cross zero. FR→EN clears the interval in greedy and beam 4.

  • FR→EN+0.543 BLEU / +0.423 chrF++ greedy; +0.336 / +0.351 beam 4. Both intervals exclude zero.
  • EN→FR+0.173 / +0.179 greedy; +0.145 / +0.001 beam 4. Not statistically significant.
  • Best step39,000; 350,000,282 tokens.

04 / Method

One benchmark. Same rows. Automatic metrics.

The preserved 350M checkpoint, both 800M continuation checkpoints, the two completed 350M data arms, and the fresh 800M ParaCrawl arm were decoded on the same retained newstest2014 segments with the same references. Nothing was truncated silently.

Evaluation setup

  • Benchmarknewstest2014 (wmt14/full), both directions
  • Retained rows2,959 EN→FR; 2,922 FR→EN; 44 and 81 overlength sources skipped
  • Documents176 per direction; bootstrap resamples documents
  • DecodersGreedy and beam 4 (length penalty 1.2, minimum 16 new tokens)
  • MetricsSacreBLEU 2.5.1, 13a cased BLEU; chrF++ with word_order=2
  • Uncertainty1,000 paired bootstrap resamples per comparison
Metric signatures and checkpoint hashes

BLEU: nrefs:1|case:mixed|eff:no|tok:13a|smooth:exp|version:2.5.1

chrF++: nrefs:1|case:mixed|eff:yes|nc:6|nw:2|space:no|version:2.5.1

06 / Caveats

What this result does not prove.

The comparison is useful because it is controlled on the evaluation side. It is not a complete quality claim.

Two different 800M comparisons

The 800M continuation uses the same 2.1M pairs as the 350M baseline; its gain reflects about 450M additional target tokens. The 800M ParaCrawl candidate adds 98,034 pairs but starts from random initialization while its baseline is a continuation. The schedule difference remains.

No human evaluation

All results are automatic metrics. The 20-row packet has blank reviewer columns and remains pending; no qualified bilingual review was performed on any reported checkpoint.

Not production-ready

Mid-20s BLEU means the model still mistranslates names, idioms, numbers and sentence structure often enough to need heavy postediting.

Scope. The page reports the completed 800M-token continuation and its final step-91,691 checkpoint, the completed 350M Tatoeba and ParaCrawl arms, and the fresh 800M ParaCrawl scale-up. The 800M ParaCrawl candidate is the dev-selected step-91,000 checkpoint from a fresh 800,004,736-token run; its baseline is the dev-selected continuation checkpoint at step 77,000. The 350M combined arm remains untrained.

01 / Comparison

Every aggregate metric improved.

Full-data step 38,000 versus scaled step 18,000 on exactly the same retained newstest2014 rows. Beam 4 is the dev-tuned setting; greedy remains the model default.

Read this first

BLEU in the low 20s is a gist-level score, not a percentage of correct sentences. The model can carry the main idea of a straightforward news sentence; it still drops details and produces wrong words.

03 / Method

One benchmark. Same rows. Automatic metrics.

Both checkpoints were decoded on the same retained newstest2014 segments with the same references. Nothing was truncated silently.

Evaluation setup

  • Benchmarknewstest2014 (wmt14/full), both directions
  • Retained rows2,959 EN→FR; 2,922 FR→EN; 44 and 81 overlength sources skipped
  • Documents176 per direction; bootstrap resamples documents
  • DecodersGreedy and beam 4 (length penalty 1.2, minimum 16 new tokens)
  • MetricsSacreBLEU 2.5.1, 13a cased BLEU; chrF++ with word_order=2
  • Uncertainty1,000 paired bootstrap resamples per comparison
Metric signatures and checkpoint hashes

BLEU: nrefs:1|case:mixed|eff:no|tok:13a|smooth:exp|version:2.5.1

chrF++: nrefs:1|case:mixed|eff:yes|nc:6|nw:2|space:no|version:2.5.1

05 / Caveats

What this result does not prove.

The comparison is useful because it is controlled on the evaluation side. It is not a complete quality claim.

Not a data-only ablation

The full-data run saw both more pairs and about twice as many target tokens as the pilot. The gain cannot be attributed to data alone.

No human evaluation

All results are automatic metrics. The 20-row packet has blank reviewer columns and remains pending; no qualified bilingual review was performed.

Not production-ready

Low-20s BLEU means the model still mistranslates names, idioms, numbers and sentence structure often enough to need heavy postediting.

Scope. The page reports the completed 350M-token full-data run and its dev-selected checkpoint. It does not report the later 800M-token continuation, which has not been started.
